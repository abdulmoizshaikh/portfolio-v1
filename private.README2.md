## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/abdulmoizshaikh/portfolio-v1.git
```

### 2. Navigate to the project

```bash
cd portfolio-v1
```

### 3. Install dependencies

Using npm:

```bash
npm install
```

Or using Yarn:

```bash
yarn install
```

### 4. Run locally

```bash
npm run dev
```

The development server will start at:

```text
http://localhost:3000
```

---

# 📦 Build the Project

The project is configured to generate a static export for GitHub Pages.

Run:

```bash
npm run build
```

This generates the static website inside the:

```text
out/
```

directory.

---

# 🚀 Deploy to GitHub Pages

This project uses the `gh-pages` package to deploy the generated `out` directory to GitHub Pages.

The deployment script is already configured in `package.json`:

```json
"predeploy": "npm run build",
"deploy": "gh-pages -d out"
```

### 1. Make sure your changes are committed

```bash
git add .
git commit -m "Update portfolio"
```

### 2. Push changes to GitHub

```bash
git push origin main
```

### 3. Deploy to GitHub Pages

Run:

```bash
npm run deploy
```

The `predeploy` script will first build the project and generate the `out` directory. Then `gh-pages` will publish the contents of `out` to the GitHub Pages branch.

---

# 🔄 Recommended Deployment Workflow

Whenever you make changes to the portfolio:

```bash
# 1. Make your code/content changes

# 2. Test locally
npm run dev

# 3. Build and deploy
npm run deploy

# 4. Commit your source changes
git add .
git commit -m "Update portfolio"

# 5. Push source code
git push origin main
```

> **Note:** `npm run deploy` handles the GitHub Pages deployment separately from pushing your source code to `main`.

# ⚙️ GitHub Pages Configuration

The repository is configured to publish the static Next.js output through the `gh-pages` deployment package.

The deployment command is:

```bash
gh-pages -d out
```

GitHub Pages should be configured to serve the deployment branch generated by `gh-pages`.

To check the configuration:

1. Open the GitHub repository.
2. Go to **Settings**.
3. Select **Pages**.
4. Check the **Build and deployment** section.
5. Make sure GitHub Pages is configured to use the branch containing the deployed `out` files.

# 📝 Updating Portfolio Content

Most portfolio content is maintained inside the `src` directory.

When updating:

- Personal information
- Experience
- Skills
- Projects
- Technologies
- Social links

search the `src` directory for the existing text and update the corresponding component/data.

For example, to search for a company name:

```bash
grep -Rni "Company Name" src
```

Or use VS Code:

```text
Cmd + Shift + F
```

and search for the company or text you want to change.
